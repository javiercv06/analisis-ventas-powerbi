# 📊 Análisis de Ventas con Python y Power BI

## 🧠 Descripción
Proyecto de análisis de datos donde se realizó limpieza, transformación y visualización de información de ventas para obtener insights de negocio.

## 🛠️ Tecnologías utilizadas
- Python (Pandas)
- Power BI
- DAX
- Excel

## 📂 Estructura del proyecto
- ventas.xlsx → datos originales
- ventas_limpio.csv → datos procesados
- analisis.py → limpieza y transformación
- dashboard.pbix → visualización en Power BI

## 📊 Análisis realizado
- Cálculo de ventas, costos y ganancias
- Análisis por producto, región y fecha
- Evaluación de rentabilidad (margen)

## 🔍 Principales insights
- Los celulares lideran en ventas y ganancia
- Tablets y notebooks tienen alto impacto en ingresos
- Productos de bajo costo tienen mayor margen pero menor volumen

## 🚀 Resultado
Se construyó un dashboard interactivo que permite analizar el rendimiento del negocio y apoyar la toma de decisiones.
